**Statistical Modelling 2**
** **
*Project overview*

Repository for our five-person Statistical Modelling 2 group project at Queen Mary University of London.
The project analysis, methods and report will be added once the assignment brief and dataset are available.
** **
*Repository Structure*

- data/ - project datasets
- R/ - R scripts and statistical analysis
- notes/ - relevant statistical concepts and revision notes
- report/ - report drafts, figures and tables
** **
*Workflow*

1. Pull latest changes before starting
2. Save the work
3. Commit changes with message
4. Push the commits to Github
5. Pull regularly to keep local copy up to date
