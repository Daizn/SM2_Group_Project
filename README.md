# Statistical Modelling II

## Project Overview

This is our five-person Statistical Modelling II group project at Queen Mary University of London.

We'll use this repository to store our code, data, notes, outputs and reports.

## Repository Structure

-`code/` - R scripts, including rough work.

-`data/` - Datasets used in the project.

-`outputs/` - Plots, tables and model results.

-`notes/` - Decision notes and records of individual contributions.

-`reports/` - Group report, individual reports and drafts.

-`docs/` - Assignment brief and other project documents.

## Workflow

1. Pull the latest changes from GitHub.
2. Save your work in the appropriate folder.
3. Update `notes/who-did-what.docx` to record your contribution.
4. Commit your changes with a clear message.
5. Push your changes to GitHub.

##Important Notes
-Avoid editing the same file as another group member at the same time.

-If someone else has changed the same file, pull their changes and resolve any merge conflicts before pushing.

-Keep your local copy up to date by pulling regularly.
